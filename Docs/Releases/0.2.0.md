JFC 0.2.0 separates the control window from click handling, so opening JFC's
window no longer changes first-click behavior. It also improves target-window
activation across multiple displays.

- `Cmd-Q` quits JFC and its click agent together.
- The click agent exits if JFC exits and is restarted if it crashes while JFC
  remains open.
- Original clicks are passed through without synthesized clicks or added delay.
- Universal macOS 14+ app for Apple silicon and Intel, signed with Developer ID
  and notarized by Apple.

When upgrading from 0.1.1, quit JFC before replacing it in Applications. Open
the new version and enable **JFC Click Agent** in System Settings → Privacy &
Security → Accessibility. The helper needs its own grant.

The attached release manifest records the source commit, build number,
notarization submission, SHA-256 checksum, and qualification status.
